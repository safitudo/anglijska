# «Тато в Європі» — EDM versions (music-first)

Parallel track of the same 7 songs, rebuilt Loco-Loco-style: the music carries
everything, lyrics are a handful of punch phrases + one hook repeated hard, story
told step by step in fragments. ~40–60 distinct words per song.

Base genre (Stan's house style):
```
Epic electronic EDM, high quality music, clear male vocals, moderate reverb, lead solo synth
```
Each track adds a small variation to that line — copy the full Style line from the file.

Each file has **two lyric blocks: EN and UA** — both are singable, generate either
(Suno handles Ukrainian vocals fine). Same structure, same hooks, so dad can hear
the same song in both languages.
