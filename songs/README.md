# Songs for Dad — Suno lyrics

5 comedy songs in caveman English. **Every word is from the 200-word deck** (only
interjections like "oh", "amen", "ring-ring" are extra) — so the songs are pure
review of what he's studying, with zero unknown words.

The humor formula: dead-serious epic genre × absurdly primitive lyrics × situations
every tourist dad knows.

## How to generate in Suno

1. suno.com → Create → **Custom** mode
2. Paste the **Style** line into "Style of Music"
3. Paste the lyrics block into "Lyrics" (keep the `[Verse]`/`[Chorus]` tags — Suno
   uses them for structure; `(parentheses)` become backing vocals)
4. Generate 2–3 variants, pick the funniest
